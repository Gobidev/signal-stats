# Signal Chat Statistics

Generate HTML statistics from your Signal chat export (`main.jsonl`).

> ⚠️ **Disclaimer:** This project was 100% generated by AI.

## Features

- **1-on-1 chat stats** — message counts, incoming/outgoing split, character volume, average length
- **Group chat stats** — member overview, activity levels
- **Trend charts** — interactive Plotly charts with hover tooltips, zoom, and pan for messages and characters over time
- **Activity timeline** — monthly message volume with bar chart
- **Message type distribution** — standard messages, stickers, polls, edits, etc.
- **Contact names** — automatically resolved from the export's contact data
- **Full details** — per-chat breakdowns with monthly sparklines and length distribution

## Usage

```bash
# Install dependencies
uv venv
source .venv/bin/activate
uv pip install -r requirements.txt

# Generate stats.html
python3 stats.py
```

Open `stats.html` in any browser.

## Requirements

- Python 3.12+
- `plotly` (see `requirements.txt`)

## Data

Place your Signal desktop export (`main.jsonl`) in the same directory as `stats.py`.

### Getting the export

**Signal Android** (beta 8.7+):  
`Settings → Chats → Export chat history`

**Signal Desktop**:  
`Preferences/Settings → Chats → Export chat history`

This generates a `main.jsonl` file containing all your messages, contacts, and chat metadata in a machine-readable JSON lines format.

> ⚠️ The export file contains your entire conversation history in plain text. Store it securely and delete it when you're done.
